# 智能背单词系统（WordFlow）

> 基于 Spring Boot 的瀑布式智能背单词系统  
> 软件工程课程设计 / 个人后端项目

## 📖 项目简介

传统背单词软件多采用单词卡模式，用户逐个翻卡，效率低且难以针对顽固错词反复强化。  
本项目提出一种**瀑布式背单词**方式：用户批量扫读单词并标记“会 / 不会”，系统实时记录答题事件，并基于事件流进行**即时分组**与**递归金字塔**复习，自动将用户不熟悉的单词逐轮筛选出来，形成个性化复习路径。

项目后端采用 Spring Boot + MyBatis-Plus + MySQL，提供标准 RESTful API，支持后续扩展至 Web、小程序、App 等多端。

## 🛠 技术栈

- **后端**：Java 21、Spring Boot 3.3.4、MyBatis-Plus 3.5.7
- **数据库**：MySQL 9.7
- **工具库**：Lombok、Knife4j (OpenAPI 3)
- **构建**：Maven
- **版本控制**：Git / GitHub
- **待引入**：Redis、RabbitMQ、Docker、JWT
